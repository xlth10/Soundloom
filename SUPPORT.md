# Soundloom Support / Soundloom 支持

Soundloom is currently a development preview and has no guaranteed support service or App Store distribution.

Soundloom 当前是开发预览项目，尚未提供承诺响应时间的支持服务，也未上架 App Store。

## Before asking for help / 提问前

Please check:

- [README](README.md) / [中文 README](README.zh-CN.md)
- [initial public scope](README.md#initial-public-scope)
- [documentation index](docs/README.md)
- existing GitHub Issues before opening a new report

请先阅读 README、当前构建范围和文档索引，并在创建报告前搜索现有 GitHub Issue。

## Bug reports / Bug 报告

A useful report includes:

- iPhone model and iOS version;
- Xcode version and commit/revision;
- whether the issue occurred in the iPhone source prototype, App Intent, Shortcut, recording, transcription, or AI-organization flow;
- exact reproduction steps;
- expected and observed result;
- sanitized logs, if relevant.

有效报告应包含 iPhone 型号、iOS 版本、Xcode 与代码版本、问题所在入口、完整复现步骤、预期与实际结果，以及必要的脱敏日志。

Never attach real recordings, transcripts, API keys, certificates, profiles, or screenshots containing private information.

不要附加真实录音、转写、API Key、证书、Profiles，或包含隐私信息的截图。

## Privacy and security / 隐私与安全

Use the private channel described in [SECURITY.md](SECURITY.md) for security or privacy vulnerabilities. Do not disclose them in a public issue.

安全或隐私漏洞请使用 [SECURITY.md](SECURITY.md) 中的私密渠道，不要在公开 Issue 披露。

## AI providers / AI 服务商

Soundloom does not operate the third-party AI services represented in its configuration. Account access, billing, rate limits, model availability, and provider-side retention are handled by each provider. Contact the provider for service-account issues.

Soundloom 不运营配置中列出的第三方 AI 服务。账号、计费、限流、模型可用性和服务商侧数据保留问题应联系对应服务商。
