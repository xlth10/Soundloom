# Documentation index / 文档索引

The files in this directory cover the current iPhone source contract, release preparation, and selected product research for Soundloom.

本目录包含 Soundloom 当前的 iPhone 源码约定、发布准备材料，以及经过筛选的产品研究。

## Current public documents / 当前公开文档

- [`DATA_FLOW.md`](DATA_FLOW.md) — local storage, Apple Speech, AI-provider, credential, and deletion boundaries.
- [`PUBLIC_RELEASE_CHECKLIST.md`](PUBLIC_RELEASE_CHECKLIST.md) — checks required before a signed binary or App Store release.
- [`RELEASE_PROCESS.md`](RELEASE_PROCESS.md) — versioning, verification, tagging, and GitHub Release procedure.
- [`open-source-ios-apps-research-2026-08-13.md`](open-source-ios-apps-research-2026-08-13.md) — reference research used to shape the repository's open-source policy.
- [`live-activity-quick-capture-plan.md`](live-activity-quick-capture-plan.md) — iPhone quick-capture and visible-recording-state design note.
- [`shortcut-owned-recording.md`](shortcut-owned-recording.md) — iOS Shortcut-owned recording and import contract.

其他平台的实现文件和详细设计记录仍保存在本地 Emergence Lab 工作区中，但不进入首次公开仓库；公开 README 只保留其设计理念摘要。
