# 快捷指令负责录音的实现方案

## 结论

App 外的录音由快捷指令自己的“录音”动作完成。VoiceCue 不在后台抢占麦克风，只接收录音文件并进入已有的 `RecordingInbox` 转写队列。

```text
操作按钮
  → 快捷指令：录音
  → 系统弹窗 / 点“完成”
  → 导入语音闪念录音（VoiceCue App Intent）
  → RecordingInbox 保存原文件
  → SpeechTranscriptionService 自动转写
  → 用户需要时在 App 内继续 AI 整理
```

## 快捷指令配置

在“快捷指令”中新建一个快捷指令，按顺序添加：

1. “录制音频”或系统同义的录音动作。
2. 将“停止录音”设置为由用户点击系统弹窗中的“完成”触发。
3. 添加 VoiceCue 的“导入语音闪念录音”动作，把第 1 步的音频作为“录音文件”传入。
4. 关闭“运行时显示”以外的自动打开 App 选项；不要在末尾添加“打开 VoiceCue”。
5. 将这个快捷指令绑定到 iPhone 操作按钮。

点击弹窗中的“完成”只负责结束系统录音；随后导入动作在后台保存音频并开始转写。默认不会跳转 App。用户点击通知、灵动岛或稍后手动打开 VoiceCue 时，再查看转写结果和 AI 卡片。

## 两条录音链路

| 场景 | 麦克风所有者 | App 内影响 |
| --- | --- | --- |
| VoiceCue App 内按钮 | VoiceCue 的 `PhoneLongRecorder` | 保持原有录音、停止和实时活动 |
| App 外操作按钮快捷指令 | 系统“录音”动作 | 只调用 `ImportVoiceCueRecordingIntent`，不改变 App 内录音 |

如果把“打开 VoiceCue”放到快捷指令末尾，系统会在导入成功后跳转 App；这不是录音完成的必要步骤，而是可选的结果查看动作。
