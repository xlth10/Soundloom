# Changelog

All notable changes to public Soundloom releases will be documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and releases will follow [Semantic Versioning](https://semver.org/) where practical for the source project. App Store build numbers are tracked separately.

## [Unreleased]

### Added

- English and Simplified Chinese public README files.
- Maintainer-provided iPhone product screenshots for the repository preview.
- English and Simplified Chinese development-preview privacy policies.
- Contribution, security, support, conduct, trademark, and third-party notice documents.
- Draft App Store metadata and a public-release checklist.
- An initial public snapshot of the iPhone SwiftUI product source.
- A public support, privacy, conduct, and private security contact.

### Changed

- Reframed the product around weaving voice into understandable context rather than a single capture surface.
- Deferred non-iPhone platform implementations from the initial public source submission while retaining a short design rationale in the README.
- Separated transcription-provider choices from optional semantic organization.
- Excluded local build caches, third-party audit screenshots, and generated design workspaces from the public source set.

### Known limitations

- The iPhone source still needs a standalone Xcode project, signing configuration, entitlements, and automated build verification.
- No stable public release or App Store build exists.
- Complete in-app deletion and credential-removal controls are release blockers.
- Cloud speech transcription providers are planned but not implemented as a complete public provider layer.
