## Description

Soundloom is a local-first voice-to-structure tool. It does more than save a recording: it helps weave scattered words, people, and events into a thread you can understand and return to.

Use Inspiration Quick Capture for a passing idea, observation, reminder, or question. Use Deep Field for interviews, meetings, field observations, and longer or multi-topic recordings. Both modes enter the same local inbox, so short thoughts and deep sessions stay in one coherent system.

Recordings are saved locally first. You can transcribe with Apple Speech and, if you choose, send the necessary transcript text to an AI provider you configure to create an inspiration record or an overview, timeline, topics, participants, and to-do items.

KEY PRINCIPLES

- Explicit recording — no ambient or always-on listening
- Clear recording state and stop control
- Original audio preserved before processing
- Local storage by default
- Optional, user-triggered AI organization
- Your own provider credentials stored in Keychain

IMPORTANT

Speech transcription may use Apple’s speech-recognition service and is not guaranteed to run offline. Optional AI organization sends transcript text to the provider and endpoint you configure. Provider accounts, charges, availability, and data practices are governed by each provider.

Do not use Soundloom for covert recording. Follow applicable recording-consent laws.
